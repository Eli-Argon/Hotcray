# Hotcray 1 (legacy)

The original AutoHotkey v1 scripts, kept for reference. Hotcray 2 (kanata +
Hotcray.ahk in the repository root) replaces all of this.

* `Hotcray-v1.ahk`: full version (Colemak + Cyrillic in AutoHotkey).
* `Hotcray-Short-v1.ahk` + `hotcray5/`: variant using an MSKLC keyboard layout.
* `CapsLock to Backspace, ....reg`: the scancode map used with Hotcray 1.
* `Remove old scancode map.reg`: **run this when switching to Hotcray 2**
  (then restart). kanata must see the real CapsLock/numpad keys.
